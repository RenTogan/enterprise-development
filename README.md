# Автомойка - Серверное приложение (Лабораторная работа №3)

REST API для автомойки на базе ASP.NET Core (.NET 10) и .NET Aspire

## Реализованный функционал
- Базовые CRUD-операции для сущностей:
  - `/api/clients` - клиенты и их автомобили
  - `/api/cars` - автомобили
  - `/api/services` - услуги мойки
  - `/api/orders` - заказы
- Аналитические запросы:
  - `GET /api/analytics/top-clients` - топ-5 клиентов по числу посещений
  - `GET /api/analytics/current-cars` - автомобили на мойке прямо сейчас
  - `GET /api/analytics/popular-services` - топ-5 наиболее популярных услуг
  - `GET /api/analytics/box-free-time` - время освобождения выбранного бокса
  - `GET /api/analytics/service-revenues` - суммарная выручка по каждой услуге

## База данных (Лабораторная работа №3)
Хранение переведено с коллекций в памяти на СУБД **PostgreSQL**
Создана начальная миграция `Initial`: схема таблиц генерируется автоматически и заполняется тестовым датасидом (по 10 записей для основных сущностей и 20 заказов).

## Оркестрация (.NET Aspire)
Запуск приложения и базы данных объединен с помощью **.NET Aspire** (`CarWash.AppHost`)
Aspire автоматически поднимает контейнер PostgreSQL в Docker с сохранением данных в томе (`DataVolume`) и прокидывает строку подключения в API
